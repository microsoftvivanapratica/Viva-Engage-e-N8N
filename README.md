# Viva Engage Weekly Summary

Projeto desenvolvido com n8n, Microsoft Entra ID, Viva Engage (Yammer API) e Microsoft Teams.

## Funcionalidades

- Coleta publicações do Viva Engage
- Filtra mensagens dos últimos 7 dias
- Filtra mensagens das últimas 24 horas
- Remove URLs e conteúdos vazios
- Gera resumo consolidado
- Publica automaticamente no Microsoft Teams

## Tecnologias

- Microsoft Entra ID
- Microsoft Viva Engage
- Yammer API
- n8n
- Microsoft Teams
- OAuth2
